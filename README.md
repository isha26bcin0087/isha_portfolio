## 🛠️ How to Customize Your Details (3 Easy Methods)

You have full control over all details. Choose whichever method you prefer:

### Method 1: The Live On-Screen Editor (Easiest & Fastest!)
1. Double-click `index.html` in your browser.
2. In the bottom-right corner, click the **`⚙️ Edit Details`** button.
3. A drawer will slide open where you can type your real phone number, LinkedIn URL, email, and intro lines.
4. Click **`💾 Apply & Save Changes`** — the website immediately updates live!
5. Optional: Click **`📥 Download Updated config.js`** to download your new configuration and replace `assets/js/config.js` permanently on disk.

### Method 2: Edit `assets/js/config.js` (Recommended for Permanence)
Open `assets/js/config.js` in any text editor (Notepad, VS Code, etc.). You will see cleanly commented fields:
```javascript
personal: {
  fullName: "Isha Sharma",
  phone: "+91 98765 43210",       // Replace with your real phone number
  linkedin: "https://www.linkedin.com/in/your-profile", // Replace with your real LinkedIn link
  email: "isha.sharma@example.com" // Replace with your real email
}
```
Save the file and refresh your browser. All 4 pages will instantly reflect your changes.

### Method 3: Directly Edit HTML Files
Every HTML file contains clear comments such as `<!-- EDIT HERE: ... -->` pointing to text, links, and descriptions so you can customize individual words or markup directly.
